# 📊 DART 공시 키워드 알림 봇

DART(전자공시시스템)에 신규 공시가 올라올 때, 미리 등록한 키워드(회사명)와 매칭되면 **Google Chat으로 알림**을 보내주는 자동 봇입니다.

- ⏰ **10분마다 자동 실행** (운영시간: 평일 09:00~20:00 KST)
- 💰 **완전 무료** (GitHub Actions, Google Sheets, DART API 모두 무료 티어 사용)
- 🔧 **코드 수정 없이** Google Sheets에서 키워드만 추가/수정
- 📱 휴대폰/PC 어디서든 Google Chat으로 알림 수신

# 🚀 셋업 가이드

## 📍 1단계: 이 템플릿으로 본인 저장소 만들기 (3분)

### 1-1. "Use this template" 버튼 클릭

이 페이지 우측 상단에 있는 **초록색 "Use this template"** 버튼을 클릭하면 작은 메뉴가 나옵니다.

- **"Create a new repository"** 선택

### 1-2. 저장소 정보 입력

새 화면이 열리면 다음과 같이 입력하세요:

| 항목 | 입력 내용 | 설명 |
|---|---|---|
| **Owner** | 본인 GitHub 계정 (자동 선택됨) | 그대로 두세요 |
| **Repository name** | `my-dart-bot` (자유롭게) | 본인이 알아볼 수 있는 이름. 영문/숫자/하이픈만 사용 |
| **Description** | `DART 공시 알림 봇` (선택) | 비워둬도 OK |
| **Include all branches** | ❌ 끄기 (기본값) | 그대로 두세요 |

그 아래 **Configuration** 섹션:

| 항목 | 선택 |
|---|---|
| **Choose visibility** | **Private** ⚠️ (★중요) |

> ⚠️ **반드시 Private**으로 설정하세요! Public으로 만들면 본인이 등록할 비밀값(API 키 등)이 노출될 위험이 있습니다.

### 1-3. 저장소 생성

화면 하단의 초록색 **"Create repository"** 버튼 클릭.

→ 1~2초 후 본인의 새 저장소가 만들어지고, 자동으로 그 페이지로 이동합니다.

> ✅ **확인**: 화면 상단에 본인이 입력한 저장소 이름(예: `내계정/my-dart-bot`)이 보이고, 옆에 🔒 자물쇠 아이콘이 있으면 Private로 잘 설정된 거예요.

## 📍 2단계: DART API 키 발급 (5분)

### 2-1. Open DART 사이트 접속 및 회원가입

1. 새 탭에서 [https://opendart.fss.or.kr](https://opendart.fss.or.kr) 접속
2. 우측 상단 **"회원가입"** 클릭
3. **개인** 선택 후 약관 동의
4. 입력:
   - 이메일, 비밀번호, 이름, 휴대폰 번호 등 입력
   - 본인인증 진행 (휴대폰 SMS 또는 인증서)
5. 가입 완료 후 로그인

### 2-2. API 인증키 신청

1. 로그인 상태에서 상단 메뉴 **"인증키 신청/관리"** 클릭
2. 좌측 메뉴에서 **"인증키 신청"** 클릭
3. 신청 양식 작성:

| 항목 | 입력 내용 |
|---|---|
| **활용 목적** | `개인 학습 및 모니터링` (자유롭게) |
| **사용 분야** | `개인` 선택 |
| **제공방식** | `JSON` 선택 (기본값일 가능성 높음) |
| 기타 항목 | 비워두거나 적당히 채우기 |

4. 양식 하단 **"신청"** 클릭 → 즉시 승인됩니다 (대기 없음)

### 2-3. 발급된 API 키 복사

1. 좌측 메뉴 **"인증키 관리"** 클릭
2. 화면에 발급된 **인증키(API 키)**가 보임 (40자 영문/숫자 문자열)
3. **복사** 버튼 또는 직접 드래그해서 복사
4. **메모장**에 임시 저장:

> ⚠️ **이 키는 비밀번호처럼** 다루세요. 외부 노출 시 본인 키가 도용될 수 있습니다.

## 📍 3단계: Google Chat 스페이스 + 웹훅 만들기 (5분)

봇이 알림을 보낼 채팅방을 만드는 단계입니다.

### 3-1. Google Chat 스페이스 추가 후 웹훅 추가

0. Chat 스페이스 만들기
1. 화면 **상단 중앙의 스페이스 이름**(`DART 공시 알림`) 클릭
2. 드롭다운 메뉴에서 **"앱 및 통합"** 선택
   - 영문: "Apps & integrations"
3. **"웹훅 추가"** 또는 **"+ Webhooks"** 버튼 클릭
4. 입력:

| 항목 | 입력 내용 |
|---|---|
| **이름** | `DART 봇` (자유) |
| **아바타 URL** | 비워두기 |

5. **"저장"** 클릭

### 3-4. 웹훅 URL 복사

저장하면 긴 URL이 생성됩니다:

```
https://chat.googleapis.com/v1/spaces/AAAA.../messages?key=...&token=...
```

1. URL 우측의 **복사 버튼** 클릭
2. **메모장**에 임시 저장:

```
[메모]
DART API 키: abc123...
Google Chat 웹훅 URL: https://chat.googleapis.com/v1/spaces/...(긴 URL)
```

> ⚠️ **이 URL도 비밀번호처럼** 다루세요. 외부 노출 시 누구나 본인 스페이스에 메시지를 보낼 수 있습니다.

## 📍 4단계: Google Sheets 키워드 시트 만들기 (3분)

키워드(모니터링하고 싶은 회사명)를 등록할 시트를 만듭니다.

### 4-1. 새 스프레드시트 만들기

1. 새 탭에서 [https://sheets.google.com](https://sheets.google.com) 접속
2. 화면 상단 **"빈 스프레드시트"**(➕ 모양) 클릭
3. 좌측 상단 **"제목 없는 스프레드시트"** 클릭 → 이름 변경: `DART 키워드` (자유)

### 4-2. 키워드 입력

다음과 같이 입력하세요:

| | A |
|---|---|
| 1 | keyword |
| 2 | 삼성전자 |
| 3 | SK하이닉스 |
| 4 | 카카오 |

> 💡 **A1 셀**은 **반드시 `keyword`** 라고 입력 (헤더). 봇은 A2부터 키워드로 인식합니다.
>
> 💡 키워드는 **한 셀에 하나씩**, 회사명 정확히 입력. 처음엔 2~3개만 등록해서 테스트한 후 추가하는 걸 추천.

### 4-3. Spreadsheet ID 복사

브라우저 **주소창**의 URL을 보세요:

```
https://docs.google.com/spreadsheets/d/1AbCdEf123XyZ456PqR789StU/edit#gid=0
                                       └────────── 이 부분 ──────────┘
```

`/d/` 와 `/edit` 사이의 긴 문자열이 **Spreadsheet ID**입니다.

위 예시에서: `1AbCdEf123XyZ456PqR789StU`

이 ID를 **메모장**에 임시 저장:

```
[메모]
DART API 키: abc123...
Google Chat 웹훅 URL: https://chat.googleapis.com/v1/spaces/...
Spreadsheet ID: 1AbCdEf123XyZ456PqR789StU
```

## 📍 5단계: Google Cloud 프로젝트 + 서비스 계정 만들기 (10분)

이게 가장 길고 복잡한 단계예요. 천천히 따라오세요!

### 5-1. Google Cloud Console 접속

1. 새 탭에서 [https://console.cloud.google.com](https://console.cloud.google.com) 접속
2. **Google Sheets와 같은 계정**으로 로그인되어 있는지 확인 (★중요)
3. 처음 사용 시 약관 동의 화면 → 동의

> ⚠️ 결제 계정 등록 화면이 나오면 **"건너뛰기"** 또는 닫기. 등록 안 해도 무료로 사용 가능합니다.

### 5-2. 새 프로젝트 만들기

1. 화면 **상단 좌측에 있는 프로젝트 선택 드롭다운** 클릭
   - 처음이면 "프로젝트 선택" 또는 "Select a project"라고 적혀 있음
2. 팝업창 우측 상단 **"새 프로젝트"** 클릭
3. 입력:

| 항목 | 입력 내용 |
|---|---|
| **프로젝트 이름** | `dart-bot` (자유) |
| **위치** | 그대로 두기 (조직 없음) |

4. **"만들기"** 클릭
5. 30초~1분 대기 → 알림에 "프로젝트 생성됨" 뜨면 완료
6. 다시 **상단의 프로젝트 드롭다운**에서 방금 만든 `dart-bot` 선택 (★중요)

> ⚠️ **프로젝트 선택 안 하면** 다음 단계에서 다른 프로젝트에 작업하게 됩니다!

### 5-3. Google Sheets API 활성화

1. 화면 **상단 검색창**(돋보기 옆)에 `Google Sheets API` 입력
2. 검색 결과에서 **"Google Sheets API"** 클릭
3. 화면에 **"사용 설정"** 또는 **"Enable"** 파란 버튼 보임
4. **클릭** → 1분 정도 대기 → 활성화 완료

> ✅ **확인**: 활성화되면 화면이 바뀌고 "API/서비스 세부정보" 같은 화면이 나옵니다.

### 5-4. 서비스 계정 만들기

1. 화면 **좌측 상단의 메뉴 버튼 ☰** 클릭
2. **"API 및 서비스"** 호버 → **"사용자 인증 정보"** 클릭
   - 영문: APIs & Services → Credentials
3. 화면 상단 **"+ 사용자 인증 정보 만들기"** 클릭
4. 드롭다운에서 **"서비스 계정"** 선택
5. **1단계** 입력:

| 항목 | 입력 내용 |
|---|---|
| **서비스 계정 이름** | `dart-bot-account` |
| **서비스 계정 ID** | 자동으로 채워짐 (그대로 두기) |
| **설명** | 비워두기 OK |

6. **"만들기 및 계속"** 클릭
7. **2단계 (역할)**: 아무것도 선택하지 말고 **"계속"** 클릭
8. **3단계 (사용자에게 액세스)**: 비워두고 **"완료"** 클릭

→ 서비스 계정 목록 화면으로 이동

### 5-5. JSON 키 다운로드 (★★중요)

1. 방금 만든 서비스 계정 이메일을 **클릭** (이메일 형태: `dart-bot-account@dart-bot-xxxxx.iam.gserviceaccount.com`)
2. 화면 상단 탭에서 **"키"** 클릭
3. **"키 추가"** → **"새 키 만들기"** 클릭
4. 팝업에서:
   - **키 유형**: **JSON** 선택 (기본값)
5. **"만들기"** 클릭

→ JSON 파일이 자동으로 본인 컴퓨터에 다운로드됩니다!

> ⚠️ **이 파일은 비밀번호와 같습니다.** 외부에 절대 공유하지 마세요!
>
> 💡 다운로드 위치: 보통 **다운로드 폴더**(Downloads). 

다운로드한 JSON 파일을 **알기 쉬운 폴더**(예: 바탕화면에 `dart-bot` 폴더 생성 후 그 안)에 옮겨두세요.

### 5-6. 서비스 계정 이메일을 Sheets에 공유

봇이 시트를 읽을 수 있도록 권한을 주는 단계입니다.

1. 5-5 화면에서 **서비스 계정 이메일** 복사
   - 예: `dart-bot-account@dart-bot-xxxxx.iam.gserviceaccount.com`
2. **4단계에서 만든 Google Sheets 탭으로 이동**
3. 우측 상단 **"공유"** 버튼 클릭
4. 팝업창 상단 입력칸에 복사한 이메일 **붙여넣기**
5. 권한 드롭다운에서 **"뷰어"** 선택
6. **"알림 보내기" 체크박스** → **체크 해제** (가짜 이메일이라 어차피 알림 못 받음)
7. **"공유"** 클릭

> ✅ **확인**: 공유 팝업에서 권한 있는 사람 목록을 보면 본인 이메일과 함께 서비스 계정 이메일이 "뷰어"로 표시되어야 정상.

## 📍 6단계: GitHub Secrets 등록 (5분)

지금까지 메모장에 모은 비밀값들을 GitHub에 안전하게 등록하는 단계입니다.

### 6-1. Secrets 등록 페이지 가기

1. **1단계에서 만든 본인 저장소**(예: `my-dart-bot`)로 이동
2. 화면 상단 탭 중 **"Settings"** 클릭
3. 좌측 메뉴에서 **"Secrets and variables"** 클릭 → 펼쳐지는 메뉴에서 **"Actions"** 클릭

### 6-2. 4개의 Secret 등록

화면 우측 상단 **"New repository secret"** 초록 버튼을 클릭할 때마다 입력 화면이 나옵니다. **4번 반복**해서 다음 4개를 등록하세요.

#### Secret 1: `DART_API_KEY`

| 항목 | 입력 |
|---|---|
| **Name** | `DART_API_KEY` (★대소문자 정확히) |
| **Secret** | 메모장의 DART API 키 (40자 문자열) |

→ **"Add secret"** 클릭

#### Secret 2: `GOOGLE_CHAT_WEBHOOK_URL`

| 항목 | 입력 |
|---|---|
| **Name** | `GOOGLE_CHAT_WEBHOOK_URL` |
| **Secret** | 메모장의 웹훅 URL (https://chat.googleapis.com/...) |

→ **"Add secret"**

#### Secret 3: `SPREADSHEET_ID`

| 항목 | 입력 |
|---|---|
| **Name** | `SPREADSHEET_ID` |
| **Secret** | 메모장의 Spreadsheet ID (예: 1AbCdEf123...) |

→ **"Add secret"**

#### Secret 4: `GOOGLE_SERVICE_ACCOUNT_JSON`

| 항목 | 입력 |
|---|---|
| **Name** | `GOOGLE_SERVICE_ACCOUNT_JSON` |
| **Secret** | 5-5에서 다운로드한 JSON 파일의 **내용 전체** |

**JSON 파일 내용 보는 법:**
- **Windows**: 다운로드한 JSON 파일 우클릭 → **"연결 프로그램"** → **"메모장"**

파일 내용은 이런 식으로 생겼어요:
```json
{
  "type": "service_account",
  "project_id": "dart-bot-xxxxx",
  "private_key_id": "...",
  "private_key": "-----BEGIN PRIVATE KEY-----\n...",
  ...
}
```

**`{` 부터 끝의 `}` 까지 전체** 복사 (Ctrl+A → Ctrl+C) → Secret 칸에 붙여넣기

→ **"Add secret"**

### 6-3. 등록 확인

4개 모두 등록되면 화면에 이렇게 보입니다:

```
Repository secrets
─────────────────────
```

## 📍 7단계: 봇 실행 및 확인 (3분)

### 7-1. Actions 탭 활성화

1. 본인 저장소 메인 화면으로 돌아가기
2. 상단 탭 **"Actions"** 클릭
3. 처음이면 안내 메시지 나옴: "Workflows aren't being run on this fork"
   - **"I understand my workflows, go ahead and enable them"** 버튼 클릭

### 7-2. 봇 수동 실행

1. 화면 좌측에 **"DART Keyword Bot"** 워크플로우가 보임 → 클릭
2. 우측 화면에 안내 배너: "This workflow has a workflow_dispatch event trigger."
3. 우측 **"Run workflow"** 드롭다운 클릭
4. 작은 팝업이 뜸:
   - **Use workflow from**: `Branch: main` (기본값 그대로)
5. 팝업의 초록색 **"Run workflow"** 버튼 클릭

→ 잠시 대기 후 페이지 새로고침하면 새 실행 항목이 생깁니다.

### 7-3. 실행 결과 확인

새 실행 항목 옆 상태 아이콘을 보세요:

- 🟡 노란색 = 실행 중 (30초~1분 대기)
- 🟢 초록색 = 성공!
- 🔴 빨간색 = 실패 → 아래 [트러블슈팅](#-트러블슈팅) 참고

**초록색이 떴으면** 실행 항목 클릭 → **run-bot** 클릭 → **Run bot** 단계의 ▶ 화살표 클릭해서 로그 확인:

```
[키워드 로드] 3개: ['삼성전자', 'SK하이닉스', '카카오']
[상태] 마지막 처리 접수번호: (없음 - 첫 실행)
[DART] 오늘 공시 총 XXX건 수신
⚠️ 첫 실행입니다. 최신 접수번호만 기록하고 다음 실행부터 정상 작동합니다.
```

> ✅ **이 메시지가 보이면 성공!** 첫 실행은 알림 안 보내는 게 정상이에요.

### 7-4. 자동 실행 확인

봇은 **10분마다 자동 실행**됩니다 (한국 시간 09:00~20:00).

> ⚠️ **첫 자동 실행은 24시간 가량 지연**될 수 있어요. GitHub Actions의 정상 동작입니다. 그동안은 **Run workflow 수동 실행**으로 보충하세요. 24시간 후엔 거의 정확히 10분마다 작동합니다.

## 일상 사용법

### 키워드 추가/삭제
1. 4단계에서 만든 Google Sheets 열기
2. A열에 키워드 추가 또는 기존 키워드 삭제
3. 다음 실행(최대 10분 후)부터 자동 반영

> 💡 **즉시 적용**하려면: 본인 저장소 → Actions → DART Keyword Bot → Run workflow 클릭

### 알림 너무 많을 때
- 시트의 키워드를 더 구체적으로 변경
- 예: `삼성` → `삼성전자` (`삼성`은 삼성SDS, 삼성중공업 등도 다 매칭됨)

### 봇 일시 정지
- 본인 저장소 → Actions → DART Keyword Bot → 우측 **"..."** → **"Disable workflow"**
- 다시 켜려면 같은 위치에서 "Enable workflow"

# 🔧 트러블슈팅

봇 실행 시 빨간색(실패)이 뜨면, 실행 클릭 → run-bot → Run bot 단계 펼쳐서 에러 메시지 확인 후 아래 참고:

### ❌ "❌ 필수 환경변수가 누락되었습니다"
- **원인**: GitHub Secret 누락 또는 이름 오타
- **해결**: Settings → Secrets and variables → Actions에서 4개 Secret 모두 있는지, 이름이 정확한지 확인

### ❌ "❌ DART API 키 오류 (status=011)"
- **원인**: DART_API_KEY 값이 잘못됨
- **해결**: Open DART 사이트에서 키 다시 확인 후, GitHub Secret을 **Update** 버튼으로 재등록

### ❌ "Google Sheets API has not been used in project"
- **원인**: 5-3 단계의 API 활성화가 안 됨
- **해결**: Google Cloud Console → API 라이브러리에서 "Google Sheets API" 활성화 → 1~2분 대기 → 봇 재실행

### ❌ "googleapiclient.errors.HttpError: 403"
- **원인**: 5-6 단계의 시트 공유가 안 됨
- **해결**: Google Sheets → 공유 버튼 → 서비스 계정 이메일이 "뷰어" 권한으로 추가됐는지 확인

### ❌ "❌ GOOGLE_SERVICE_ACCOUNT_JSON 형식 오류"
- **원인**: JSON 내용 복사 시 일부 누락 또는 손상
- **해결**: 다운로드한 JSON 파일을 **메모장**으로 다시 열어서 `{` 부터 `}` 까지 **전체** 복사 (Ctrl+A → Ctrl+C) → Secret Update

### ❌ 첫 실행 후 알림이 안 와요
- **원인**: 정상입니다! 첫 실행은 "현재 시점 기록"용이고, 다음 실행부터 신규 공시 알림이 옵니다.
- **확인**: 키워드와 매칭되는 신규 공시가 실제로 발생해야 알림이 옴. DART 사이트에서 공시 발생 시간 확인 가능.

### ❌ 자동 실행이 시작되지 않아요
- **원인**: GitHub Actions의 자동 스케줄은 첫 24시간 동안 들쭉날쭉합니다.
- **해결**: 24시간 정도 기다리면 안정화됩니다. 그동안은 Run workflow 수동 실행.

### ❌ 알림이 너무 많아요
- **원인**: 키워드가 너무 광범위함
- **해결**: 키워드를 더 구체적으로 변경
